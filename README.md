# WoBo40

**Seeed XIAO nRF52840 Plus** + ZMK で動く、1Uトラックボール内蔵の40%オーソリニアキーボードです。
Plusの裏面パッドを使った **8行×6列マトリクス(行2段重ね方式)** で、シフトレジスタ等のICなしに47キー+トラックボールを実現します。

```
┌───┬───┬───┬───┬────┬───┬────┬────┬────┬───┬────┬────┐
│ Q │ W │ E │ R │ T  │Esc│BSpc│ Y  │ U  │ I │ O  │ P  │
├───┼───┼───┼───┼────┼───┼────┼────┼────┼───┼────┼────┤
│ A │ S │ D │ F │ G  │Tab│Ent │ H  │ J  │ K │ L  │ -  │
├───┼───┼───┼───┼────┼───┼────┼────┼────┼───┼────┼────┤
│ Z │ X │ C │ V │ B  │Sft│Sft │ N  │ M  │ , │ .  │ /  │
├───┼───┼───┼───┼────┼───┼────┼────┼────┼───┼────┼────┤
│Ctl│Opt│Cmd│SYS│英数│Spc│Spc │かな│●TB │fn │LClk│RClk│
└───┴───┴───┴───┴────┴───┴────┴────┴────┴───┴────┴────┘
 ←──── 左ブロック C1〜C6 ────→←──── 右ブロック C7〜C12 ────→
```

- 47キー (物理4行 × 12列、トラックボール位置はキーなし)
- `●TB` = 1U トラックボール (PAW3222 センサー)
- Bluetooth / USB 両対応、ZMK Studio 対応

## 部品構成

| 部品 | 個数 | 備考 |
|---|---|---|
| Seeed XIAO nRF52840 Plus | 1 | 無印のXIAO nRF52840ではピン不足のため**Plus必須** |
| PAW3222 トラックボールモジュール | 1 | 1U サイズ、3.3V/SPI 接続のもの |
| ダイオード 1N4148 | 47 | キーごとに1本 (COL2ROW) |
| キースイッチ / キーキャップ | 47 | MX など |
| リチウムポリマー電池 / 昇圧回路 | 1式 | 電源基板は別途 (下記) |

## マトリクス構成 (行2段重ね方式)

物理は4行×12列ですが、GPIOを節約するため **左ブロック (C1〜C6) と右ブロック (C7〜C12) に分割**し、
右ブロックの行線を別の4本にして列線を左右で共用します。電気的には **8行×6列 = 14本** です。

- **行線は左右ブロックで別配線**です。C6とC7の間で行線を切り離してください
- 列線は左右で共用します (下表)
- ダイオードは通常のCOL2ROW: **カソード(帯)を行側に**向けて、キーごとに1本

### 行線

| 物理行 | 左ブロック (C1〜C6) | 右ブロック (C7〜C12) |
|---|---|---|
| 1段目 (Q行) | Row0 = D0 | Row4 = D2 |
| 2段目 (A行) | Row1 = D11 | Row5 = D13 |
| 3段目 (Z行) | Row2 = D1 | Row6 = D3 |
| 4段目 (最下段) | Row3 = D12 | Row7 = D14 |

### 列線 (左右共用)

| 列線 | 左ブロックの物理列 | 右ブロックの物理列 |
|---|---|---|
| Col0 = D10 | C1 | C7 |
| Col1 = D19 | C2 | C8 |
| Col2 = D9 | C3 | C9 (最下段はトラボのためキーなし) |
| Col3 = D18 | C4 | C10 |
| Col4 = D8 | C5 | C11 |
| Col5 = D17 | C6 | C12 |

## ピンアサイン

PCBの配線しやすさを優先し、**行8本を上辺・列6本を下辺に、それぞれ連番で並ぶよう**割り当てています
(XIAO Plusは表ピンと裏パッドが交互に並ぶため、パッドの物理順に合わせています)。

**上辺** (左→右: 行8本 → ADC → トラックボール3本)

| 位置 | ピン | nRF52840 | 役割 |
|---|---|---|---|
| 1 | D0 | P0.02 | 行0 |
| 2 | D11 (裏面) | P0.15 | 行1 |
| 3 | D1 | P0.03 | 行2 |
| 4 | D12 (裏面) | P0.19 | 行3 |
| 5 | D2 | P0.28 | 行4 |
| 6 | D13 (裏面) | P1.01 | 行5 |
| 7 | D3 | P0.29 | 行6 |
| 8 | D14 (裏面, NFC1) | P0.09 | 行7 |
| 9 | D4 | P0.04 (AIN2) | 電池電圧監視 ADC (任意・ファーム未使用) |
| 10 | D15 (裏面, NFC2) | P0.10 | PAW3222 nCS |
| 11 | D5 | P0.05 | PAW3222 SDIO |
| 12 | D16 (裏面) | P0.31 | **使用禁止** (電池電圧測定用 AIN7_BAT) |
| 13 | D6 | P1.11 | PAW3222 SCLK |

**下辺** (左→右: 電源 → 列6本 → MOTION)

| 位置 | ピン | nRF52840 | 役割 |
|---|---|---|---|
| 1〜3 | VBUS / GND / 3V3 | — | 電源 |
| 4 | D10 | P1.15 | 列0 |
| 5 | D19 (裏面) | P1.07 | 列1 |
| 6 | D9 | P1.14 | 列2 |
| 7 | D18 (裏面) | P1.05 | 列3 |
| 8 | D8 | P1.13 | 列4 |
| 9 | D17 (裏面) | P1.03 | 列5 |
| 10 | D7 | P1.12 | PAW3222 MOTION |

- D14/D15 (NFCピン) はファーム側でGPIO化済み (`CONFIG_NFCT_PINS_AS_GPIOS=y`)。SPIクロックには使わず、行スキャンとnCSのみに割り当てています
- D16 (P0.31) は電池残量の測定に内部で使われるため、マトリクスには使いません
- ADCが使えるのは D0〜D5 のみ。行の連番配置を優先し、電池電圧監視は D4 (AIN2) に配置しています
- 公式ピン図には過去にP1.03/P1.07 の誤記実績あり。基板化前に回路図/KiCadで裏面パッドを要確認

### トラックボール接続 (JL1 コネクタ)

| JL1ピン | 信号 | XIAO |
|---|---|---|
| 1 | 3.3V | 3V3_OUT |
| 2 | CS (NCS) | D15 |
| 3 | MOTION | D7 |
| 4 | SDIO | D5 |
| 5 | SCLK | D6 |
| 6 | GND | GND |

- 3線SPIです。モジュールの SDIO を D5 に接続 (MOSI/MISO はファーム側で同一ピンに束ねています)
- 電源は必ずXIAOの **3V3_OUT** から (USB接続時も生きているため)

## 電源について

XIAO のバッテリー運用は電源基板 (昇圧・逆接保護・USB逆流防止) を別途用意します。
NiMH/1.5V を TPS61021A で3.3Vへ昇圧し、XIAO の BAT ピンへ供給する構成を想定しています。
詳細は回路図を参照してください。

## ファームウェアのビルド

GitHub Actions で自動ビルドされます。

1. このリポジトリに push すると Actions が走ります
2. Actions の実行結果ページから Artifacts をダウンロード:
   - `wobo40-studio` … ZMK Studio 対応版 (通常はこちら)
   - `wobo40` … Studio なしの軽量版
   - `settings-reset` … ペアリング情報などを消去するリセット用

## 書き込み方法

1. XIAO のリセットボタンを素早く2回押す (UF2 ブートローダーモードに入り、USBドライブがマウントされる)
2. ダウンロードした `.uf2` ファイルをドライブにコピーする
3. 自動的に再起動して書き込み完了

動作がおかしくなった場合は `settings-reset` を一度書き込んでから、本体ファームウェアを入れ直してください。

## キーマップ

`config/wobo40.keymap` で定義しています。Mac / JIS 環境を想定しています。

| レイヤー | 出し方 | 内容 |
|---|---|---|
| 0: Base | 常時 | 通常入力。`英数`=LANG2 / `かな`=LANG1。トラボ右隣の2キーが左右クリック |
| 1: Mouse | ボールを動かすと自動有効 (400ms で解除) | 最下段右端が中クリック |
| 2: Fn | `fn` (トラボの右隣) 押下中 | 数字、F1〜F12、記号 (`=` `[` `]` `;` `'`、JISの `\_` `¥|`)、矢印キー、Home/End。**トラックボールはスクロールに切替** |
| 3: Sys | `SYS` (英数の左) 押下中 | Bluetooth 切替 (Q〜T=接続先0〜4、`Esc`位置=ペアリング解除)、`A`=リセット、`S`=ブートローダー、`-`位置=Studio アンロック、メディアキー |

最下段の並び: `Ctrl Opt Cmd SYS 英数 Space Space かな [トラボ] fn 左クリック 右クリック`

中央2列(6・7列目)は `Esc`/`BSpc`、`Tab`/`Enter`、`Shift`/`Shift`、`Space`/`Space` を配置しています。

### ZMK Studio

`wobo40-studio` 版を書き込めば、[ZMK Studio](https://zmk.studio/) から USB 経由でキーマップをリアルタイムに変更できます (Sys レイヤーの Enter = `&studio_unlock` でアンロック)。

## トラックボールの調整

- **感度(CPI)**: `boards/shields/wobo40/wobo40.overlay` の `res-cpi`(範囲 608〜4826、38刻み)
- **オートマウス/スクロール**: 同 overlay の `trackball_listener` の input processor で定義
  - `zip_temp_layer 1 400` … ボール移動で Mouse(1) レイヤーを400ms有効化
  - `scroller { layers = <2>; ... }` … Fn(2) レイヤー中はスクロールに変換
- **XY/スクロールの反転・入れ替え**: `zip_xy_swap_mapper` や scaler 系 processor を追加して調整

PAW3222 ドライバ自体にはスクロール/オートマウス機能が無いため、ZMK標準の input processor で実装しています。

ドライバ: [sekigon-gonnoc/zmk-driver-paw3222](https://github.com/sekigon-gonnoc/zmk-driver-paw3222)
